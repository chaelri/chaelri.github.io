# Charlie + Karla shared Minecraft mods

Both of you must have the same list. Target: Minecraft 26.2, Forge 26.2-65.1.5, played over LAN.

| Mod | What it does |
| --- | --- |
| OptiFine 26.2 HD U K2 pre5 | Performance, shaders, C-key zoom (preview build, the only 26.x release) |
| Xaero's Minimap | Minimap with the other player shown, automatic death marker |
| Xaero's World Map | Full map, shows the other player and your last death point |

Setup (each PC): install Minecraft 26.2 once, install Forge 26.2-65.1.5 from files.minecraftforge.net, then run `install-mods.ps1`. Start the Forge 26.2 profile.
